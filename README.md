# 刷题助手 · Grind

纯前端刷题工具：**导入 Excel 题库**，分组闯关 + 遗忘曲线 + 错题本。

- 在线使用：https://skekon806.github.io/grind-shuati/
- 本地使用：直接双击 `index.html`

首次打开是空状态，导入一个题库文件即可开始。

---

## 功能

### 题库
- **导入 .xlsx / .xls / .csv**，解析全部在浏览器本地完成，文件不上传
- 导入后**停留在结果页**，显示解析题数、板块分布、被跳过的行及原因
- 多题库并存、随时切换；每个题库的进度与错题独立保存

### 刷题
- 10 题一组，**必须全对才算过**
- 组内某题**连续答对 3 次**即可跳出重复队列
- 每组共需完成 **3 次全对**（含首次），间隔：10 分钟 → 1 天 → 3 天
- 答题后自动跳转（对 0.6s / 错 1.4s），本组结束自动下一组或重做
- 键盘：`A–N` 选选项，`空格` 确认 / 跳过等待

### 错题本
- 答错自动收录，记录**错误次数、最近错误时间、连对次数**
- 连续答对 **2 次**自动移出（改 `app.js` 里的 `WRONG_CLEAR` 可调）
- 按板块筛选、按错误次数排序、点开看答案与全部选项
- 一键重练（每次最多 20 题，优先错得最多的）

## 导入格式

第一行是表头，至少包含 **题目** 和 **答案**：

| 序号 | 所属题库 | 题型 | 题目 | 答案 | 选项A | 选项B | 选项C | 选项D |
|---|---|---|---|---|---|---|---|---|
| 1 | 按揭业务 | 单选题 | 借款人年龄不得超过（）周岁 | C | 55 | 60 | 65 | 70 |
| 2 | 消贷业务 | 多选题 | 下列属于禁入行业的有（） | A,B,D | 房地产 | 制造业 | 小贷 | 娱乐业 |
| 3 | 应知应会 | 判断题 | 房龄加贷款期限不得超过 60 年 | A | 正确 | 错误 | | |

- **列名可换**：题目 / 题干 / 问题；答案 / 正确答案；所属题库 / 分类 / 模块 / 章节
- **选项有几个就解析几个**，三种写法都认：
  1. 多列：`选项A`「选项B」… 或 `选项1`「选项2」…
  2. 直接写在题目里：`下列说法正确的是（）A. 甲 B. 乙 C. 丙 D. 丁`
  3. 合并成一列「选项」，用换行分隔
- **答案写法**：单选 `C` 或 `3`；多选 `A,B,C`；判断可用 `A/B`，也可直接写 `正确/错误`、`对/错`、`√/×`
- **题型列可省略**，会按答案个数自动判断单/多选
- 选项列数量与题目里写的不一致时，**以题目里写明的为准**
- 完全重复的题目自动去重，跳过的行会在报告里列明原因

## 目录结构

```
index.html                界面与样式
app.js                    全部逻辑（题库管理 / 刷题 / 错题本 / 导入解析）
vendor/xlsx.full.min.js   SheetJS，用于解析 xls/xlsx
```

## 数据与迁移

进度存在浏览器 `localStorage`，按题库分别保存：

| Key | 内容 |
|---|---|
| `grind_banks_v1` | 题库列表与当前选中 |
| `grind_bank_<id>` | 导入的题库内容 |
| `grind_prog_<id>` | 该题库的进度、错题、设置 |

换设备时重新导入同一份题库即可继续刷，但**进度不会跟着走**（没有做备份/导出功能）。

## 本地开发

没有构建步骤，改完刷新即可。题库全部由 xlsx 导入，不再内置。
