# 刷题助手 · Grind

一个纯前端的刷题工具：**可以导入 Excel 题库**，支持分组闯关、遗忘曲线复习和错题本。

- 在线使用：https://skekon806.github.io/grind-shuati/
- 本地使用：直接双击 `index.html`（需与 `bank.js`、`app.js`、`vendor/` 同目录）

---

## 功能

### 题库
- 内置一套「客服助理上岗资格证」题库
- **导入 .xlsx / .xls / .csv**，解析全部在浏览器本地完成，文件不上传
- 多题库并存，随时切换；每个题库的进度、错题独立保存

### 刷题
- 10 题一组，**必须全对才算过**
- 组内某题**连续答对 3 次**即可跳出重复队列，不必陪着错题无限重来
- 每组共需完成 **3 次全对**（含首次），间隔按遗忘曲线：10 分钟 → 1 天 → 3 天
- 答题后自动跳转（对 0.6s / 错 1.4s），本组结束自动下一组或重做
- 键盘：`A–N` 选选项，`空格` 确认 / 跳过等待

### 错题本
- 答错自动收录，记录**错误次数、最近错误时间、连对次数**
- 连续答对 **2 次**自动移出（次数可在 `app.js` 的 `WRONG_CLEAR` 调整）
- 按板块筛选，按错误次数排序，点开看正确答案与全部选项
- 一键重练（每次最多 20 题，优先错得最多的）

## 导入格式

第一行是表头，至少包含 **题目** 和 **答案** 两列：

| 序号 | 所属题库 | 题型 | 题目 | 答案 | 选项A | 选项B | 选项C | 选项D |
|---|---|---|---|---|---|---|---|---|
| 1 | 按揭业务 | 单选题 | 借款人年龄不得超过（）周岁 | C | 55 | 60 | 65 | 70 |
| 2 | 消贷业务 | 多选题 | 下列属于禁入行业的有（） | A,B,D | 房地产 | 制造业 | 小贷 | 娱乐业 |
| 3 | 应知应会 | 判断题 | 房龄加贷款期限不得超过 60 年 | A | 正确 | 错误 | | |

规则：

- **列名可换**：题目 / 题干 / 问题；答案 / 正确答案；选项A~选项N（最多 14 个）；所属题库 / 分类 / 模块 / 章节
- **答案写法**：单选 `C`；多选 `A,B,C` 或 `A、B、C`；判断可用 `A/B`，也可直接写 `正确/错误`、`对/错`、`√/×`
- **题型列可省略**，会按答案个数自动判断单/多选
- 完全重复的题目会自动去重，跳过的行会在导入结果里列出原因

## 目录结构

```
index.html            界面与样式
app.js                全部逻辑（题库管理 / 刷题 / 错题本 / 导入解析）
bank.js               内置题库（可选，删掉也能用，首页会提示导入）
vendor/xlsx.full.min.js   SheetJS，用于解析 xls/xlsx
```

## 数据存储

全部在浏览器 `localStorage`：

| Key | 内容 |
|---|---|
| `grind_banks_v1` | 题库列表与当前选中 |
| `grind_bank_<id>` | 导入的题库内容 |
| `grind_prog_<id>` | 该题库的进度、错题、设置 |

换设备用「导出进度」导出 JSON 迁移（目前导出的是进度，不含题库本体）。

## 本地开发

没有构建步骤，改完直接刷新页面即可。若要新增内置题库，修改 `bank.js`：

```js
window.BANK = {
  secs: {
    "板块名": {
      weight: 33,                       // 可选，首页显示"占分"
      questions: [
        { q: "题干", o: ["选项1","选项2"], a: [0], t: "single", s: "来源" }
      ]
    }
  }
};
```

`a` 是正确项下标数组；`t` 取 `single` / `multi` / `judge`。
